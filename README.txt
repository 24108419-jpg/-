BÀI NỘP: RESPONSIVE WEB DESIGN

Tệp gồm:
- index.html: trang web mẫu
- style.css: CSS và hai Media Queries theo yêu cầu

Cách xem:
1. Giải nén thư mục.
2. Mở index.html bằng trình duyệt hoặc Visual Studio Code.
3. Có thể dùng DevTools để thử các độ rộng 772px và 998px.

Lưu ý: Đây là bản mẫu độc lập do chưa có bộ mã nguồn khởi đầu từ GitHub của bài tập.
Nếu giảng viên yêu cầu chỉnh sửa đúng dự án mẫu, thay nội dung tương ứng trong style.css của dự án gốc.
